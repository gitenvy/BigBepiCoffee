# Coffee Shop Ordering System

A desktop Coffee Shop Ordering System built with Java and JavaFX. The application provides a graphical user interface (GUI) for customers to browse drinks, customize orders, and manage a shopping cart before checkout.

## Features

- ☕ Browse available coffee and beverages
- ➕ Add drinks to an order
- ✏️ Customize drink options
- 💰 Automatic price calculation
- 📋 Order summary
- 🖥️ JavaFX graphical user interface

## Technologies

- Java
- JavaFX
- Object-Oriented Programming (OOP)

## Learning Outcomes

This project demonstrates:

- Object-oriented programming principles
- MVC (Model-View-Controller) architecture
- JavaFX GUI development
